기존 브라우저의 영어·일본어 프로필과 학습 기록을 보존하는 것이 기준입니다. 새 계정의 서버 기록은 사용자별로 분리합니다. 기존 로컬 기록을 자동으로 계정에 합치지 않고, 사용자가 가져오기를 선택하는 흐름을 구현했습니다.

아직 확인하지 않은 사항

실제 D1 통합 테스트 15개와 달력 사례 13개가 통과했으며, 달력 사례는 호스트 시간대 3곳에서 확인했습니다. 프로덕션 빌드도 통과했습니다. 이번 버전의 실제 브라우저 UI 검증은 실행 환경 문제로 수행하지 못했습니다. 비공개 v2 배포와 호스팅 DB 테이블 4개는 확인했으며, 인증된 실제 HTTP 점검에서 사이트 첫 화면이 404를 반환해 배포 파일 제공 경로를 수정했습니다. 수정본 빌드와 정적 경로 회귀 테스트 9개가 통과했으며 재배포를 기다립니다. 기존 배포의 운영 API에서는 위조 세션이 비인증으로 처리되고, 없는 계정의 로그인이 거절되는 것을 확인했습니다. 현재 사이트를 사용할 수 있다고 확인한 상태는 아닙니다. 실제 가입·로그인·기기 간 기록 공유의 브라우저 검증은 대기 중입니다. 사이트는 현재 소유자만 접근 가능한 비공개 상태이며, 외부 사용자 접근은 아직 결정하지 않았습니다.
