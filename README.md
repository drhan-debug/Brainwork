# Bloom · 함께 자라는 언어 습관

한국어 사용자를 위한 개인 언어 학습 앱입니다. Bloom 자체 이메일·비밀번호 계정으로 가입하고 영어·일본어·스페인어·이탈리아어 중 하나를 선택합니다. React 19/Vite 화면과 Cloudflare Worker API, D1 계정·학습 저장소를 함께 사용합니다. ChatGPT 로그인이나 별도 음성 API 키는 필요하지 않습니다.

## 실행

Node.js 22 이상과 npm을 사용합니다.

```sh
npm ci --cache /tmp/brainwork-npm
npm run build
npm run db:migrate
npm run dev
```

Wrangler가 표시하는 localhost 주소(기본 8787)에서 계정 기능을 포함한 앱을 엽니다. Node.js 22 이상이 필요합니다. `npm run build`는 Vite 정적 화면과 이를 포함한 `dist/server/index.js` Worker, D1 마이그레이션을 만듭니다. 로컬 마이그레이션은 별도의 개발 D1에만 적용됩니다. 선택적인 `npm run dev:ui`와 `npm run preview`는 화면만 제공하며 계정 API는 제공하지 않습니다. 서버 코드는 [server/README.md](server/README.md), 요청 계약은 [server/API.md](server/API.md)를 참고하세요.

호스팅용 산출물을 준비했지만 이 문서의 계정 서비스는 아직 배포 완료로 간주하지 않습니다. 실제 공개 URL과 호스팅 D1 마이그레이션·연결은 배포 결과로 별도 확인해야 합니다.

## 학습 흐름

- 이메일·비밀번호로 가입하거나 로그인하면 자신의 이름, 언어, 목표, 문장·단어 복습 일정과 학습 기록을 불러옵니다. 학습이나 가져오기를 시작한 뒤에는 언어를 변경할 수 없습니다. 브라우저 제목도 자신의 학습 언어를 표시합니다.
- 홈의 **오늘의 문장 세션**에서 생활 속 30가지 상황을 고릅니다. 네 언어 모두 상황마다 네 문장, 언어별 120문장을 제공합니다. 홈과 나의 학습의 상황 카드에서도 바로 시작할 수 있습니다.
- 하나의 전체 화면 세션에서 **장면 이해 → 듣기 → 따라 말하기 → 기억해서 말하기 → 오늘의 퀴즈 → 완료 요약**을 진행합니다. 세션 동안 한 상황의 문장만 사용합니다. 일본어는 후리가나와 가나 읽기를 지원합니다.
- 듣기와 말하기는 브라우저 TTS / ASR을 사용한 프로토타입입니다. 마이크 대신 직접 입력할 수 있습니다. 회상과 퀴즈에서는 먼저 답을 시도하고 예문과 비교합니다. 완료 요약은 닫을 때까지 유지되며, 닫으면 시작했던 페이지로 돌아갑니다.
- **복습 노트**는 기한이 된 문장을 상황별로 묶습니다. 선택한 한 상황의 복습 대상만 다시 연습합니다. 세션에서 한 번이라도 틀린 문장은 다음 현지 날짜의 자정부터 복습할 수 있습니다. 이후 재시도에 성공해도 그 세션의 실패 기록은 유지됩니다. 모든 시도를 맞힌 문장은 3 → 7 → 14 → 30 → 60일 간격으로 복습합니다. 복습일 전 성공적인 추가 연습은 기존 일정을 미루지 않습니다. 문장별 다음 복습 일정도 펼쳐 볼 수 있습니다.
- **기존 단어 코스와 짧은 대화**를 펼치면 원래 영어 15단어, 일본어 9표현, 세 상황의 독립 연습과 짧은 대화를 이용할 수 있습니다. 기존 단어의 1 → 3 → 7 → 14 → 30일 일정과 어려운 단어의 10분 복습은 문장 일정과 별도로 유지됩니다.
- **학습 리포트 / 설정**에서는 완료 세션의 횟수, 실제 경과 시간, 학습 날짜, 목표와 이름을 확인하거나 변경합니다. 새 문장 세션은 완료 때 각 문장의 최종 결과와 세션 기록을 한 번만 반영합니다. 중간 종료한 문장 세션은 완료 기록이나 문장 일정을 변경하지 않습니다.

## 계정, 데이터와 이전 기록 가져오기

계정마다 프로필(이름·영어/일본어·일일 목표·시간대)과 학습 기록을 D1에 저장합니다. 다른 기기에서 같은 Bloom 계정으로 로그인하면 서버에 저장된 기록을 불러옵니다. 학습자는 `learned`, `reviews`, `reviewStages`, `sessions`, `minutes`, `name`, `goal`, `dates`, `dailyMinutes`, `sentenceProgress`를 가지며 문장 ID는 `en:cafe_order:1`처럼 고정되어 있습니다. 문장 복습은 서버 시각과 계정 시간대를 기준으로 계산합니다.

정상 학습은 전체 기록을 덮어쓰지 않고 문장 세션·단어 답변 등의 작업으로 저장합니다. 작업 ID의 중복 방지와 원자적 리비전 검사를 사용하며, 다른 기기의 변경과 충돌하면 최신 기록을 불러와 미저장 작업을 다시 적용합니다. 네트워크 오류 시 대기 작업은 현재 창의 메모리에만 남으므로 저장 전에 창을 닫거나 새로고침하면 잃을 수 있습니다. 다른 탭에서 계정을 바꾸면 이전 계정의 작업을 새 계정에 저장하지 않습니다.

로그아웃은 대기 중인 작업의 저장을 먼저 기다립니다. 저장에 실패하면 로그인 상태와 대기 작업을 유지하며, 다시 저장하거나 미저장 변경을 직접 취소한 후 로그아웃할 수 있습니다. 요청은 30초 후 시간 초과 안내를 표시합니다. 연속 학습과 최근 7일 리포트는 계정 시간대의 달력 날짜를 사용하므로 일광절약시간 변경에도 하루씩 계산합니다.

이전 브라우저의 `bloom-profiles-v2`(아내·영어 또는 남편·일본어)나 `bloom-state`(영어)는 자동으로 서버에 보내지 않습니다. 로그인한 사용자가 한 기록을 직접 선택해야 하며, 계정 언어와 일치하고 아직 서버 학습 기록이 없는 계정에서 한 번만 가져올 수 있습니다. 가져오기 후 원래 로컬 키는 변경하거나 삭제하지 않습니다. 가져온 학습 기록은 검증하며 계정의 이름과 목표는 그대로 유지합니다. 다른 사람의 기록은 각자의 계정에서 별도로 가져오세요.

비밀번호는 12–128자이며, 무작위 salt와 scrypt 해시만 저장합니다. 로그인 세션은 무작위 토큰을 사용하며 서버에는 토큰 해시를, 브라우저에는 HttpOnly·Secure·SameSite 쿠키를 저장합니다. 비밀번호·원본 세션 토큰을 기록하지 않으며 계정 요청에는 동일 출처 검사, 크기 제한, 로그인 시도 제한을 적용합니다. 가입 이메일은 로그인 식별자이며 이메일 소유 인증이나 메일 전송은 제공하지 않습니다.

가입 및 복구 후 한 번 표시되는 **복구 코드**를 안전한 곳에 저장하세요. 코드를 사용하면 비밀번호와 복구 코드를 바꾸고 기존 모든 세션을 종료합니다. 비밀번호와 복구 코드를 모두 잃으면 앱에서 복구할 수 없습니다. 서버에 동기화된 기록은 브라우저 데이터 삭제 후에도 계정에 남습니다. 관리자용 계정 삭제·데이터 내보내기 기능은 아직 제공하지 않습니다.

## 단계별 학습과 사용자 피드백

각 언어는 **입문 10상황 → 기초 10상황 → 응용 10상황**, 총 30상황·120문장입니다. 인사와 짧은 요청에서 시작해 생활 속 설명, 예약 변경·분실물·알레르기·집 수리·은행·우체국·여행 문제·업무 조율·의견 나누기로 이어집니다. 앱의 단계는 학습 순서이며 공인 CEFR 등급이나 수료 자격을 의미하지 않습니다. 필요한 상황은 자유롭게 먼저 고를 수 있습니다.

다음 추천은 학습 경로에서 모든 문장을 아직 맞히지 못한 첫 상황입니다. 단순히 열어 보거나 두 번 틀리고 넘어간 상황은 완료로 세지 않습니다. 네 문장을 성공적으로 마치면 다음 상황을 추천합니다. 기존 영어·일본어 80문장의 ID와 기록은 유지합니다. 계정은 가입할 때 한 언어를 선택하며 학습 시작 후 언어를 바꾸지 못하는 기존 정책을 유지합니다. 로컬 데모는 네 언어를 각각 저장합니다.

로그인한 사용자는 **피드백** 메뉴에서 오류, 학습 내용 수정, 새 상황·기능 제안을 서버에 보낼 수 있습니다. 내용(최대 2,000자), 언어, 선택한 상황, 화면 이름과 접수 시각을 D1에 저장합니다. 하루 최대 10건이며, 타임아웃 후 같은 제출을 재시도해도 중복 저장하지 않습니다. 사용자는 자신의 접수 내역과 처리 상태를 확인합니다. 피드백은 학습 저장 대기열과 독립적으로 처리합니다. 로컬 데모는 서버에 피드백을 보내지 않습니다.

운영자는 앱의 **전체 피드백 확인**에서 최신 피드백과 작성자 이메일을 보고 `접수됨 → 검토·개선 예정 → 반영 완료`로 처리합니다. 서버의 `FEEDBACK_ADMIN_ACCOUNT_ID`에 지정된 Bloom 계정만 운영자 권한을 얻습니다. **운영자 이메일 주소를 코드에서 관리자 판정에 사용하지 않습니다.** 현재 앱은 이메일 소유 인증을 하지 않으므로, 주소만 보고 자동으로 관리자 권한을 주지 않습니다. 배포 소유자가 실제 운영자 계정을 확인한 뒤 해당 계정의 불변 ID를 서버 환경변수에 설정해야 합니다. 이 변수가 없으면 일반 피드백 접수는 동작하고 운영자 조회는 차단됩니다. 로컬에서는 `.dev.vars`에, 호스팅에서는 Sites 런타임 환경변수에 설정 후 재배포합니다. 공개 저장소에 계정 ID나 자격 증명을 추가할 필요는 없습니다.

피드백은 운영자 검토를 위한 보관함이며 이메일 자동 발송이나 자동 코드 변경은 하지 않습니다. 운영자가 의견을 검토하고 변경을 테스트·배포한 뒤 처리 상태를 갱신합니다. 피드백에 비밀번호나 민감한 개인정보를 적지 않도록 안내합니다.

스키마 변경은 로컬 `migrations/0002_feedback.sql`과 호스팅 `drizzle/0001_dark_scarlet_witch.sql`을 각각 해당 환경에 적용합니다. 같은 DB에 두 마이그레이션 세트를 중복 적용하지 않습니다. 기존 마이그레이션은 변경하지 않았습니다.

추가 검증: `npm run test:curriculum`, `npm run test:feedback`, `npm run test:ui`(React 서버 렌더링 검사).

## 음성 기능

앱은 녹음된 원어민 음원이나 발음 점수를 제공하지 않습니다. 브라우저 음성 합성은 영어 `en-US`, 일본어 `ja-JP`를 사용합니다. 음성인식도 같은 언어를 지정합니다. 음성 합성용 목소리, 마이크, 음성인식은 브라우저와 운영체제에 따라 지원이 다릅니다. 마이크에는 HTTPS 또는 localhost와 사용자 권한이 필요하며 음성인식 서비스의 네트워크 연결이 필요할 수 있습니다.

음성 기능이 없거나 권한이 거부되면 안내와 직접 입력으로 계속 학습할 수 있습니다. 음성인식은 인식한 문장과 예문을 비교하는 연습이며, 정밀 발음 평가나 가짜 발음 점수를 제공하지 않습니다. 띄어쓰기와 문장부호는 비교에서 제외합니다. 일본어 입력은 기기의 일본어 키보드로 할 수 있습니다.

앱에 포함된 SVG 장면 이미지는 외부 이미지 서비스 없이 표시됩니다.

## 키보드 접근성

새 문장 세션은 전체 화면 대화상자로 열리고 제목으로 초점을 옮깁니다. 뒤의 앱을 비활성화하고 키보드 초점을 세션 안에 유지하며 닫으면 실행 버튼으로 돌아갑니다. 기존 학습·설정·도움말·완료 대화상자를 열면 닫기 버튼으로 초점을 옮기고, Tab / Shift+Tab은 대화상자 안에서 순환합니다. 대화상자 뒤의 화면은 `inert`로 비활성화하며 Escape, 닫기 버튼, 배경 클릭으로 닫으면 원래 실행 버튼으로 돌아갑니다. 완료 화면에서 단어장으로 이동하는 등 실행 버튼이 사라졌다면 현재 메뉴 버튼으로 돌아갑니다. 학습에서 완료 화면으로 바뀔 때도 초점을 새 대화상자 안에 유지합니다. 보조 설명과 작은 동작 텍스트는 실제 밝은 배경에서 4.5:1 이상의 대비를 사용합니다.

## 검증

`npm run build`로 프로덕션 빌드를 확인합니다. 계정 API 통합 검증은 `npm run test:accounts`로 실제 Miniflare/D1에서 실행합니다. `npm run test:calendar`는 계정 시간대, 일광절약시간 전환과 로컬 데모의 날짜 계산을 검증합니다. 브라우저 회귀 검증은 시스템 Chromium이 있는 환경에서 아래처럼 실행합니다. 다른 Chromium 실행 파일을 쓰려면 `CHROMIUM_PATH`를 지정하세요. 실제 마이크 입력과 음성인식 서비스 응답은 기기에서 별도로 확인해야 합니다.

```sh
npm ci --prefix tests
npm test --prefix tests
```
