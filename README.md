# Bloom · 나의 영어가 자라는 곳

이미지 연상과 간격 반복에서 영감을 받은 개인용 영어 학습 웹 앱입니다. React 19와 Vite로 만들었으며 별도 서버나 API 키가 필요하지 않습니다.

## 실행

Node.js 22 이상과 npm을 사용합니다. 현재 환경에서는 Node.js 24로 확인했습니다.

```sh
cd /workspace/Brainwork
npm ci --cache /tmp/brainwork-npm
npm run dev -- --port 5173
```

배포용 정적 파일 생성은 `npm run build`, 생성한 앱 확인은 `npm run preview`를 실행합니다. 결과물은 `dist/`입니다.

## 구현한 기능

- 일상·여행·자기소개 코스: 코스별 5개, 총 15개 이미지 단어 카드와 한국어 뜻·연상 힌트·예문
- 영어 단어와 예문 듣기: 브라우저의 음성 합성 사용
- 기억 여부에 따른 복습 예약: 기억한 단어는 24시간 뒤, 어려운 단어는 10분 뒤 재등장
- 복습 세션에 들어올 때 단어 목록을 고정하여 순서대로 복습
- 단어장 검색, 오늘과 누적 학습 시간, 완료 횟수, 연속 학습 일수
- 이름과 일일 목표 설정, 브라우저 `localStorage`에 학습 기록 저장
- 말하기 연습: 지원 브라우저의 영어 음성인식 결과 표시와 문장 입력 연습
- 데스크톱·모바일 반응형 레이아웃

## 범위와 제약

이 버전은 기기 한 대에서 사용하는 MVP입니다. 회원가입, 계정별 데이터 분리, 여러 기기 동기화, 결제 기능은 없습니다. 뇌새김의 브랜드·콘텐츠를 복제하지 않은 독립 디자인입니다.

음성 기능은 브라우저와 운영체제 지원에 따라 다릅니다. 마이크는 HTTPS 또는 localhost와 사용자 권한이 필요하며 음성인식 제공자의 네트워크 연결이 필요할 수 있습니다. 실제 AI 발음 평가 모델이나 음소별 채점은 연결하지 않았으므로 발음 점수를 만들지 않습니다. 입력 연습은 표시된 예문과 문장을 비교합니다.

이미지 연상 장면은 앱에 포함된 자체 SVG 일러스트를 사용하여 외부 이미지 서비스 없이 표시됩니다. 학습 기록은 현재 브라우저에만 저장되며 사이트 데이터를 삭제하면 사라집니다. 학습 시간은 완료한 세션의 실제 경과 시간을 분 단위 소수점 첫째 자리로 기록합니다.

## 검증

- `npm run build` 성공
- Chromium/Playwright에서 일상 5개 단어 학습 완료, 새로고침 후 단어장·검색·설정 유지, 코스 필터 및 코스별 콘텐츠 확인
- 기한이 지난 단어 3개를 저장한 상태에서 빠짐없이 복습 완료
- 오늘 학습 시간과 누적 학습 시간 구분, 말하기의 문장 입력 연습 확인
- 390px 모바일에서 가로 넘침 없음 및 카드 진행 확인
- 실제 마이크 입력 및 음성인식 서비스 응답은 자동 검증하지 않음
