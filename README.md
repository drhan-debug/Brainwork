# Bloom · 함께 자라는 언어 습관

한국어 사용자를 위한 부부 언어 학습 앱입니다. 아내는 영어, 남편은 일본어를 선택하고 각자의 기록으로 학습합니다. React 19와 Vite로 만들었으며 별도 서버나 API 키가 필요하지 않습니다.

## 실행

Node.js 22 이상과 npm을 사용합니다.

```sh
npm ci --cache /tmp/brainwork-npm
npm run dev -- --port 5173
```

`npm run build`로 `dist/`에 배포용 정적 파일을 만들고, `npm run preview`로 확인합니다.

## 학습 흐름

- 상단 **학습자 선택**에서 아내 · 영어 / 남편 · 일본어를 고릅니다. 이름, 목표, 문장·단어 복습 일정과 학습 기록은 각각 분리됩니다. 브라우저 제목도 현재 학습자의 언어를 표시합니다.
- 홈의 **오늘의 문장 세션**에서 생활 속 20가지 상황을 고릅니다. 두 언어 모두 상황마다 네 문장, 총 80문장을 제공합니다. 홈과 나의 학습의 상황 카드에서도 바로 시작할 수 있습니다.
- 하나의 전체 화면 세션에서 **장면 이해 → 듣기 → 따라 말하기 → 기억해서 말하기 → 오늘의 퀴즈 → 완료 요약**을 진행합니다. 세션 동안 한 상황의 문장만 사용합니다. 일본어는 후리가나와 가나 읽기를 지원합니다.
- 듣기와 말하기는 브라우저 TTS / ASR을 사용한 프로토타입입니다. 마이크 대신 직접 입력할 수 있습니다. 회상과 퀴즈에서는 먼저 답을 시도하고 예문과 비교합니다. 완료 요약은 닫을 때까지 유지되며, 닫으면 시작했던 페이지로 돌아갑니다.
- **복습 노트**는 기한이 된 문장을 상황별로 묶습니다. 선택한 한 상황의 복습 대상만 다시 연습합니다. 세션에서 한 번이라도 틀린 문장은 다음 현지 날짜의 자정부터 복습할 수 있습니다. 이후 재시도에 성공해도 그 세션의 실패 기록은 유지됩니다. 모든 시도를 맞힌 문장은 3 → 7 → 14 → 30 → 60일 간격으로 복습합니다. 복습일 전 성공적인 추가 연습은 기존 일정을 미루지 않습니다. 문장별 다음 복습 일정도 펼쳐 볼 수 있습니다.
- **기존 단어 코스와 짧은 대화**를 펼치면 원래 영어 15단어, 일본어 9표현, 세 상황의 독립 연습과 짧은 대화를 이용할 수 있습니다. 기존 단어의 1 → 3 → 7 → 14 → 30일 일정과 어려운 단어의 10분 복습은 문장 일정과 별도로 유지됩니다.
- **학습 리포트 / 설정**에서는 완료 세션의 횟수, 실제 경과 시간, 학습 날짜, 목표와 이름을 확인하거나 변경합니다. 새 문장 세션은 완료 때 각 문장의 최종 결과와 세션 기록을 한 번만 반영합니다. 중간 종료한 문장 세션은 완료 기록이나 문장 일정을 변경하지 않습니다.

## 데이터와 이전 버전 호환

현재 브라우저의 `localStorage` 중 `bloom-profiles-v2`에 `{version: 2, active, learners: {wife, husband}}` 형태로 저장합니다. 각 학습자에는 `learned`, `reviews`, `reviewStages`, `sessions`, `minutes`, `name`, `goal`, `dates`, `dailyMinutes`, `sentenceProgress`가 있습니다. `sentenceProgress`는 `en:cafe_order:1` 같은 고정 문장 ID를 키로 하고 `{stage, dueAt, lastOutcome, lastReviewedAt}`를 저장합니다. 두 언어의 콘텐츠는 독립 모듈이며 공통 스키마로 검증됩니다. 문장 기록에서는 해당 언어의 유효한 ID와 날짜만 유지하고 잘못된 단계·결과·마지막 학습 시각은 안전한 기본값으로 정규화합니다. 기존 단어 기록과 다른 학습자의 데이터는 유지합니다.

처음 실행할 때만 기존 `bloom-state` 데이터를 아내의 영어 기록으로 복사합니다. 기존 데이터의 유효한 필드와 값(복습 시각 포함), 알 수 없는 추가 필드를 보존하며, 원본 키는 변경하지 않습니다. v2 데이터와 이전 데이터 모두 학습자별로 검증합니다. 잘못된 이름·목표·횟수·시간은 기본값으로 복구하고, 단어·날짜 목록과 복습·일별 시간 기록에서는 유효한 항목을 유지합니다. 한 학습자의 잘못된 값 때문에 다른 학습자의 기록을 초기화하지 않습니다. 이후에는 v2 데이터를 읽으므로 학습자를 바꾸거나 새로고침해도 이전 데이터를 다시 덮어쓰지 않습니다. 기존 영어 단어 키는 호환을 위해 유지하고, 일본어는 `ja-` 접두사의 고정 ID를 사용합니다. 새 복습 단계는 원래 복습 날짜가 지난 뒤 학습할 때부터 적용됩니다.

같은 브라우저의 여러 탭에서는 저장 직전에 최신 기록을 읽고 변경한 학습자의 항목만 갱신합니다. 다른 탭의 변경 사항도 화면에 반영하며, 각 탭에서 선택한 학습자는 유지합니다. 저장이 실패하면 해당 학습자의 변경 작업을 이 창의 메모리에 보관합니다. 다음 변경 또는 다른 탭의 저장 알림 때 최신 저장 기록에 미저장 작업을 순서대로 다시 적용해 저장을 시도하므로, 뒤이은 변경이나 다른 학습자의 저장으로 미저장 기록을 잃지 않습니다. 저장에 성공한 작업만 대기 목록에서 지우며, 실패 중 창을 닫거나 새로고침하면 아직 저장되지 않은 작업은 사라집니다. 동시에 저장하는 경우를 위한 서버 동기화나 잠금은 제공하지 않습니다.

회원가입, 여러 기기 동기화, 서버 저장은 없습니다. 브라우저 사이트 데이터를 삭제하면 기록도 사라집니다. 실제 시간은 완료한 세션에만 더해집니다. 기존 단어 코스는 중간에 종료해도 이미 확인한 단어의 복습 일정을 저장합니다. 문장 세션은 완료 시점에 선택한 문장 전체를 함께 저장합니다. 저장 실패 중에는 메모리의 대기 작업을 유지하며 재시도 때 같은 세션을 중복 집계하지 않습니다.

## 음성 기능

앱은 녹음된 원어민 음원이나 발음 점수를 제공하지 않습니다. 브라우저 음성 합성은 영어 `en-US`, 일본어 `ja-JP`를 사용합니다. 음성인식도 같은 언어를 지정합니다. 음성 합성용 목소리, 마이크, 음성인식은 브라우저와 운영체제에 따라 지원이 다릅니다. 마이크에는 HTTPS 또는 localhost와 사용자 권한이 필요하며 음성인식 서비스의 네트워크 연결이 필요할 수 있습니다.

음성 기능이 없거나 권한이 거부되면 안내와 직접 입력으로 계속 학습할 수 있습니다. 음성인식은 인식한 문장과 예문을 비교하는 연습이며, 정밀 발음 평가나 가짜 발음 점수를 제공하지 않습니다. 띄어쓰기와 문장부호는 비교에서 제외합니다. 일본어 입력은 기기의 일본어 키보드로 할 수 있습니다.

앱에 포함된 SVG 장면 이미지는 외부 이미지 서비스 없이 표시됩니다.

## 키보드 접근성

새 문장 세션은 전체 화면 대화상자로 열리고 제목으로 초점을 옮깁니다. 뒤의 앱을 비활성화하고 키보드 초점을 세션 안에 유지하며 닫으면 실행 버튼으로 돌아갑니다. 기존 학습·설정·도움말·완료 대화상자를 열면 닫기 버튼으로 초점을 옮기고, Tab / Shift+Tab은 대화상자 안에서 순환합니다. 대화상자 뒤의 화면은 `inert`로 비활성화하며 Escape, 닫기 버튼, 배경 클릭으로 닫으면 원래 실행 버튼으로 돌아갑니다. 완료 화면에서 단어장으로 이동하는 등 실행 버튼이 사라졌다면 현재 메뉴 버튼으로 돌아갑니다. 학습에서 완료 화면으로 바뀔 때도 초점을 새 대화상자 안에 유지합니다. 보조 설명과 작은 동작 텍스트는 실제 밝은 배경에서 4.5:1 이상의 대비를 사용합니다.

## 검증

`npm run build`로 프로덕션 빌드를 확인합니다. 브라우저 회귀 검증은 시스템 Chromium이 있는 환경에서 아래처럼 실행합니다. 다른 Chromium 실행 파일을 쓰려면 `CHROMIUM_PATH`를 지정하세요. 실제 마이크 입력과 음성인식 서비스 응답은 기기에서 별도로 확인해야 합니다.

```sh
npm ci --prefix tests
npm test --prefix tests
```
